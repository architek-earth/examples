# AliExpress examples

Prepared 2026-11-16. [Listing](https://apify.com/architekture/aliexpress-search-scraper).

Run `python example.py` with your own `APIFY_TOKEN`. This starts a bounded run only when executed. Review pricing and preview limits first.

Import `n8n-workflow.json`, select a Header Auth credential named Authorization with value Bearer YOUR_TOKEN, and run it manually. It is inactive by default; no token is embedded. Do not retry an ambiguous start without checking whether a run exists.
